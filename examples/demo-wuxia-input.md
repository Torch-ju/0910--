# 演示输入：东方武侠（小虾米 · 慕容雪）

- 用途：`书中人` 演示与本地测试的「故事想法」输入。
- 使用位置：设定工作台 → 预设选「东方武侠」→ 粘贴「主推版」→ 点「生成」。
- 边界：本文件是演示输入文本，不是数据契约；`examples/story_world.json`、`examples/character_profiles.json` 仍是 Schema 示例，两者不互相替代。
- 状态：文本已定稿；未做真实模型复验，实际生成质量与耗时未验证。

## 主推版（约 900 字，信息最全）

```
我想写一个传统的东方武侠故事，主角就是我自己——一个在江湖里没有名号的“小虾米”。

我在临江城的渡口讨生活，替人跑腿、送信、搬货，勉强糊口；会几手三脚猫的拳脚，遇上真正的练家子，一招都接不住。我记性好、路熟，答应过的事一定办到，也见不得不平的事。我没想过当什么大侠，只想在这条江边安稳活下去。渡口的人都叫我“小虾米”，正经名字可以后面再定。

慕容雪是临江慕容家的大小姐。慕容家在城里开着最大的镖局和茶庄，她是家里唯一的女儿，从小由重金请来的武师教艺，剑法和轻功都极好，在江湖上已经小有名气。她人前冷淡有礼，其实心软，见不得仗势欺人；也正因为身份，她做事讲究分寸，从不轻易欠别人人情。

两年前的一个雪夜，她替我解过一次围，从那天起我就一直悄悄喜欢她。她大概早忘了，我也从没敢说出口。我很清楚我们之间隔着什么：她是慕容家的大小姐，我只是渡口边一个没人记得的小人物。要说愿望，我只希望有一天能站得离她近一点，哪怕只是能替她挡一刀。

故事的味道想要传统武侠那种：恩怨、情义、身不由己，人走在江湖里，很多事由不得自己。主角的成长要慢，一步一步熬出来，不要突然得到绝世武功，也不要用巧合把差距抹平；感情线也慢慢来，单相思、克制、说不出口，不要写成一路逆袭的爽文。

开局我想要这样一个画面：上元灯会，我替茶庄送灯笼走过长街，正好撞见慕容雪在桥头被几名不知来历的刀客围住。她一个人本应付得来，我却还是冲了上去，三两下就被人打翻在雪地里，反倒害她分神。

有几条我很在意的边界：
1. 不出现神怪、妖法这类东西，武功再高也在人力之内，出手会有疲惫、伤痛和代价。
2. 主角是我的化身，遇到事怎么选、说不说出口由我决定，不要替我表态、替我承诺。
3. 慕容雪要有自己的目标、判断和难处，不要写成只会等人的花瓶。
4. 主角可以慢慢变强，但每一步都要有代价和过程，不能一夜之间变成高手。
5. 不要出现现代词汇和网络腔调，语言古雅一点，更像那个世界。

另外留几个问题我们一起定：主角的大名和身世；慕容家是正是邪；我对她的心意会不会有回应；灯会上这群刀客是谁派来的。
```


## 演示时预期被识别的边界

- 硬约束：不出现神怪妖法；主角关键选择由用户决定；慕容雪有自己的目标；成长要慢；不用现代词汇。
- 待确认问题：主角姓名与身世、慕容家立场、心意是否有回应、刀客来历。
- 人物线索：主角（用户控制）、慕容雪（NPC）。

## 来源与合规

- “小虾米”“慕容雪”来自用户设定，为原创人物；其余具体地名与组织（临江城、慕容家镖局与茶庄、上元灯会等）为本文件模拟补全，可替换。
- 用“传统武侠”定调，不点名模仿具体作品，符合 PRD 非目标中排除的“模仿或复制既有作品”。
