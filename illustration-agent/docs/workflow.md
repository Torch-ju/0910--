# 工作流与策略

```text
小说样本
  → 提炼视觉圣经草案
  → 用户/运营确认后锁定
  → 章节结构化正文
  → 独立识别人设视觉信息 + 选择关键场景
  → 更新本 Agent 的人物视觉档案
  → 主要人物有无已确认标准参考图？
      ├─ 无：生成候选 → 用户确认 → 回到章节处理
      └─ 有：组装 Seedream 提示词和参考图
  → 参考图只提取人物外观，不继承其背景、姿势或写真构图
  → Seedream 4.5 生成单张 2560×1440 横向叙事场景图
  → 立即转存 TOS（Seedream URL 只作为临时中转）
  → 自动审核剧情、人物、画质、合规
      ├─ 不通过：最多再试 3 次
      └─ 通过：原子切换为当前版本
  → Web 按段落 ID + 文本哈希插入正文
```

## 关键场景

一章只选一个场景，优先级为：决定剧情走向的事件、核心人物冲突/选择、视觉辨识度高的情节。只使用本章证据片段，不补写背景，不提前使用后续章节信息。画面通常控制在 1–3 个核心人物。

每个场景计划必须单独给出：

- 具体环境：原文能够支持的时间、地点、天气、建筑或空间状态；
- 关键动作：这一刻正在发生的剧情事件；
- 主体互动：人物之间，或人物与事件/环境之间的反应和空间关系；
- 镜头构图：16:9 中景、全景或环境叙事镜头，明确前中后景。

正式章节图不得是人物写真、肖像、角色海报、证件照或单人静态站姿。即使只出现一个人物，也必须表现该人物正在对具体事件或环境作出反应，且故事环境必须承担清晰的叙事作用。

## 人物一致性

- 稳定层：五官、年龄感、体型、发型、标志性特征和时代身份。
- 动态层：本章服装、伤势、情绪、姿态、随身物件和身份状态。
- 稳定层进入标准参考图；动态层每章从小说正文重新提取。
- 标准参考图仅锁定五官、发型、年龄感和体型；参考图的背景、姿势、灯光及镜头不得复制到正式章节图。
- 未获用户确认的主角参考图不能用于正式章节生图。
- 小说后续明确揭示稳定外貌发生冲突时，应生成新的参考图候选并再次确认，而不是静默覆盖。

## 自动审核阈值

- 剧情一致性 `>= 0.80`
- 场景叙事性 `>= 0.85`；写真式画面最高只能记为 `0.40`
- 人物一致性 `>= 0.85`
- 画面质量 `>= 0.75`
- 合规检查必须通过

所有条件同时满足才自动展示。审核模型的 `passed` 结论不能绕过应用层硬阈值。

## 失败与版本

- `maxRetries=3` 表示首次请求外最多重试 3 次，共 4 次。
- 失败尝试单独记录，便于排查模型、存储和审核问题。
- 用户“重新生成”必须写原因并创建新业务版本。
- 新图通过审核之前，旧的当前图保持不变；新图通过后，旧图转为 archived。
- TOS 对象键包含不可变逻辑 ID 与版本号，并使用 `forbidOverwrite`。

## 生成速度

- 单章仍保持“一次只生成一张”，避免模型返回多图造成延迟和人物漂移。
- 多章节调用 `processChapters(inputs, { concurrency: 3 })`，默认并发 3 路，可配置为 1–4。
- 章节任务互不阻塞；某章审核失败时，仅该章进入最多 3 次自动重试，其他章节可正常完成。
- 视觉圣经和主要人物参考图应在批量生成前完成锁定，避免把等待审批时间计入生图耗时。

## 合规

提示词预处理会替换明显血腥描述，并强制加入负面约束。自动审核检查明显鲜血、伤口特写、断肢、内脏、色情、违法内容、畸形肢体、文字、logo、水印和写真式构图。可以表现追逐、兵刃对峙、冲锋等战斗张力。
