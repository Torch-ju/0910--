# 书中人

### 写下第一句话，世界就开始生长

书中人是一张和 AI 一起写故事的桌子。

你只需要说出一个念头：一个人、一段旅程，或者一个“如果……”。书中人会陪你把它慢慢长成一个有世界、有来处、有人情关系的故事。你始终是主角，故事怎么走，由你决定；AI 负责记住那些已经发生的事，也在合适的时候，让故事里的人真正来问你一句话。

> 这不是替你写完一本书，而是和你一起，把一本书写出来。

## 你可以怎么用

- 写下一个故事想法，选择东方武侠或西方魔幻的起点。
- 让书中人先帮你搭好世界、人物和开局；不喜欢的地方，直接改。
- 进入故事，用自己的话说行动、对白和选择。
- 在人物来问你时，以主角身份回应，让决定真正改变后面的故事。
- 随时回到故事设定、人物记忆和世界时间线，继续整理你的世界。
- 写完一段就保存、归档，并导出 Markdown 或完整 JSON 备份。

## 为什么是“书中人”

很多 AI 写作工具擅长一次生成一段漂亮的文字，但故事写长以后，人物会忘记自己说过的话，世界也容易前后不一致。

书中人把“写作”做成了一个可以反复回来的地方：

- 你控制主角，AI 不替你做关键决定。
- 人物有自己的身份、关系、动机和记忆，不只是一次性对白。
- 世界框架、人物画像、事件时间线和正文一起演化。
- 每一轮写作都有保存和恢复，刷新页面也不会把正在写的故事弄丢。
- AI 生成的内容会标明来源；建议可以接受、修改，也可以拒绝。

## 在本地打开

项目目前是本地运行的 Next.js 应用，适合直接体验和继续开发。

### 一键启动

双击根目录的 `start.py`，或在 PowerShell 中运行：

```powershell
python start.py
```

脚本会检查依赖、启动开发服务，并在 `http://127.0.0.1:3000` 就绪后打开浏览器。

### 手动启动

```powershell
npm ci
npm run dev
```

然后访问 <http://127.0.0.1:3000>。

### 配置模型

在项目根目录创建本地 `.env.local`，参考 `.env.example` 填写模型服务配置：

```text
LLM_BASE_URL=你的 OpenAI 兼容服务地址
LLM_MODEL=你的文本模型名称
LLM_API_KEY=只保存在本机的密钥
```

密钥只应放在 `.env.local`，不要放进前端、截图、README 或 GitHub。应用不会设置本地请求次数上限，但实际可用额度仍取决于模型服务商的配额与限流。

## 当前体验边界

这是一个正在打磨中的本地产品原型。当前已具备故事创建、世界与人物共创、对话式写作、人物互动、记忆与时间线整理、刷新恢复和作品导出；真实模型的输出质量、响应速度和可用性仍取决于本地配置的模型服务。当前没有账号系统、云端同步或公网部署。

仓库中的 `examples/demo-wuxia-input.md` 提供了一份可以直接粘贴体验的武侠开场输入。

## 技术栈

Next.js App Router、React、TypeScript、Tailwind CSS、Ajv JSON Schema，以及服务端主 Agent 编排。故事世界、人物画像和时间线使用共享契约保存，写作过程保留可恢复的检查点。
