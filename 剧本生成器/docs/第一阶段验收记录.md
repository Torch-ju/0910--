## 修复过的问题

- 用户明确选择前先模糊认可时，候选组绑定改为查找最近有效候选组，避免因中间澄清回复丢失指代。
- 编辑框已有内容时标签查询不稳定，补充明确可访问名称；桌面、手机完整编辑流程重新通过。
- 生成期间编辑资料的结果必须标过期，且过期候选无法直接采用。
- 撤回改为资料 ID，覆盖用户直接编辑及由建议采用生成的两类资料。
- 请求重放使用指纹检查，内容不同不能复用同一个请求 ID。
- 切换项目或提交期间继续输入，不清空另一个项目或新输入的草稿。
- 初始迁移已冻结为具体建表操作，避免未来模型修改改变 0001 的含义。

## 如实保留的限制

1. 没有真实模型 Key/型号/预算配置，未运行真实模型调用；认证、限流、超时、格式与用量契约使用本地 MockTransport 验证，不能等同于真实网络验证。
2. 当前前端显式标注模拟体验；固定回复只能验工程，不能评价故事质量。
3. SSE 当前返回校验后的完整结果，未实现真实逐字模型流。首字延迟、真实总耗时、费用和长期引导质量均待测。
4. 长对话使用正式资料与有限近期消息，不含摘要生成/向量检索。资料超预算会显式失败且保留输入；后续需实现更长篇幅支持。
5. 当前每次修改保守地使其他待定建议过期，后续可细化为依赖级影响分析。
6. 开发依赖仍有 ESLint 9 支持期限警告及 Starlette TestClient 的 httpx/BlockingPortal 弃用警告；本次没有隐藏警告。ESLint 10 实测与 React 插件不兼容，暂保留可运行版本。
7. 本环境 Turbopack 生产 CSS 构建因子进程端口失败，已用同框架官方 Webpack 路径成功构建。
8. 尚未覆盖真实手机键盘、读屏器完整操作、多用户登录、公网部署、章节正文或全文一致性。
