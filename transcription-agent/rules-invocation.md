# 转写调用规则 v2

完整规则统一见 [工作区主 Agent 调用契约](../../MAIN_AGENT_RULES.md)。

1. 仅有效剧情输入触发；设定修订、查询与闲聊不调用转写。
2. 主 Agent 先完成角色演绎，再完成世界旁白，最后调用转写。
3. narrator_output 必须为 input.schema.json 规定的对象；不再接收旧字符串格式。
4. 转写成功后先校验正文和场景，再处理记忆、摘要与章节，全部通过才原子提交。
5. 结构错误最多修复一次，网络不明不自动重发。用户明确恢复时复用已完成步骤。
6. 章节工具只归档已校验正文并保存来源轮次，不将原始聊天拼成小说。
7. 用户控制权与已确认设定优先；对白不是设定修改授权，模型不能授予用户确认状态。
